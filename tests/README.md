# 业务、界面与设备验证

这里保存自动化测试与合成样本，用于检查功能、数据保存和界面表现。测试夹具不作为应用默认课表，也不打入 APK。

| 路径 | 作用 | 入口 |
|---|---|---|
| `unit/` | 导入、恢复、课次等 TypeScript 逻辑测试 | `npm test` |
| `browser/` | 浏览器用户流程、持久化、外观和响应式回归 | `npm run check:ui` |
| `android/` | 提醒、日历、原生导航和更新的设备验证 | 阅读各脚本后指定隔离设备运行 |
| `integrity/` | 工程约束和本地资源完整性检查 | `npm run check` |
| `helpers/` | 浏览器启动、导航等测试共用工具 | 由测试调用 |
| `fixtures/` | 合成课表和规则自测数据 | 由测试读取 |

命令均从仓库根目录执行。Android 的 JUnit 测试位于 `app/src/test/`；浏览器模拟回调不能代替真实设备验证。

截图、日志与结果写入忽略的 `build/evidence/`。环境、测试分组与重跑方式见 [开发说明](../docs/development.md)。
