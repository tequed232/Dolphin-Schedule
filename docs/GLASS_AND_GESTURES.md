# 导航材质与手势

一级导航使用独立的实体表面。Android 由 WebView 外的平台 View 显示，网页由 `PrimaryNavigation` 显示；原生能力确认后只保留对应入口。竖屏置底，横屏和宽屏置于侧边，内容按实际栏尺寸占位。

背景图片固定在独立底层，模糊和材质按用户偏好配置；导航材质不依赖旧透镜参数。旧外观偏好仍可读取，迁移不清空课表或用户资源。

工具栏随内容正常滚动。二级任务、键盘和对话框处理导航占位与系统安全区，避免遮挡输入或操作。弹窗挂在独立根节点，不重复继承页面缩放。

点击课程查看详情；长按或明确操作进入布局编辑。拖动只在编辑状态生效，滚动、点按和拖动分开处理。返回、切页和结束操作退出编辑；取消手势不保存。

Android 边缘返回将开始、进度、取消和提交传递给网页。返回优先处理当前对话框、未保存草稿和编辑状态，再操作页面栈。用户取消返回时保留当前输入和位置。

系统减少动态效果偏好覆盖元素与伪元素的动画和过渡；详情打开也遵守该偏好。正常模式保留反馈，性能降级不改变点击、返回或保存语义。布局及业务交互规则见 [导航与导入](NAVIGATION_INTERACTION.md)。
