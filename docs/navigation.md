# 课表导航与导入交互

列表、平铺、搜索和设置是四个一级入口，共用已提交课表和选中日期。底部居中悬浮胶囊高 56dp、最大宽 320dp；选中项显示图标和名称，其他项只显示图标，每项触摸范围至少 48dp 并保留无障碍名称。胶囊覆盖内容，周围没有整条实色底板；内容末尾可滚到它上方。

## 查看与横滑

列表日期条支持滑动与月历跳转；平铺按自然周显示七天，窄屏可横向浏览被遮住的星期。周次按钮可上一周、下一周或回到今天。当前时间更新不会强制抢回用户正在查看的日期。

平铺每条普通横向手势只由一个滚动容器处理：开始时尚能浏览星期，就在该次手势内浏览星期；已经到边缘后，再向外滑动才切换周次。一次手势最多翻一周，短距离取消回原位，反向新手势可中断旧动画。课程块内的普通横滑也遵守同样规则，不因经过卡片而失效。

页面切换对当前图层做短距离移动与淡入，不同时保留两份大课表。胶囊选中背景单独移动，避免逐帧重排触摸目标。性能模式降低效果时使用更轻的过渡；具体流畅度仍需目标设备验证。

## 编辑与草稿

| 操作 | 行为 |
|---|---|
| 点击课程 | 打开详情，查看教材、地点、备注并主动导航 |
| 长按课程 | 进入布局编辑，只显示当前课程的把手 |
| 拖动主体 | 改变星期与起始节次，保持原有连续节数 |
| 上下把手 | 单独改变开始或结束节次，至少保留一节 |
| 拖到可视边缘 | 继续横向或纵向滚动，不在拖动中跨周改写周次 |
| 松手 | 校验课程、作息和当前数据后提交，冲突先确认 |
| 系统取消、返回或点空白 | 取消预览或退出编辑，不保存未确认位移 |
| 点击左侧时间 | 编辑节次名及起止时间，或删除未占用节次 |
| 切换一级入口 | 退出布局编辑并保留日期；滚动位置按页面状态处理 |

收起的空闲午休不是拖动目标。有课程占用的节次不能直接删除；删除空闲节次时同步重排后续课程索引，保留实际上课时间。辅助功能另提供按天、按节移动和把手调整。

返回优先处理当前弹窗、菜单、未确认草稿和编辑状态，再返回上一级。二级任务保留顶部返回，隐藏一级胶囊。导入和教材草稿保存到应用私有文件，恢复后仍需核对确认。

## 预测式返回

设置等二级页面、课程编辑和教材编辑接入 `PredictiveBackHandler`：系统侧滑进度直接驱动当前内容的缩放、圆角和轻微位移，取消手势回到原位，完成手势才执行原来的返回逻辑。尚未保存的课程、教材与导入草稿仍需确认，不因侧滑进度而删除或保存。手势期间若页面已改变，不再重复返回另一级。

没有子页面时不拦截系统返回，由系统处理返回桌面动画；键盘、底部弹层与弹窗按自身返回优先级处理。降低效果时保留手势完成和取消的语义，关闭内容形变。Android 14 及以上可提供返回进度；旧系统和三键返回继续使用同一个完成逻辑。系统厂商和手势设置会影响实际动画。

教务浏览有网页历史时优先返回上一页，支持手势进度和取消复原；没有网页历史时由系统处理 Activity 返回。无需额外权限。实现依据：[Android 预测式返回进度](https://developer.android.com/develop/ui/compose/system/predictive-back-progress)。

## 打开地图

课程详情、主页导航和行程卡片的目的地按钮共用地图启动器。选择高德时，优先通过官方 `androidamap://poi` URI、指定 `com.autonavi.minimap` 打开本地客户端；未安装、没有对应入口或系统拒绝启动时，回退原 HTTPS 网页。百度保持现有网页入口。实现依据：[高德 Android 关键词搜索](https://lbs.amap.com/api/amap-mobile/guide/android/search)。

搜索词仅包含学校与识别出的楼栋，完整教室号继续显示在课表和行程卡片中。当前没有校内楼栋的已确认坐标，因此打开的是地点搜索，需在高德中核对地点并开始路线；不会把文本或猜测的坐标当成准确导航目的地。客户端接受启动请求也不代表已经找到地点或开始路线。

通知按钮先验证当前行程令牌、目标和有效期；过期、已结束或课程已变化时提示重新选择课程，不打开旧目标，也不创建或延长行程。按钮直接启动 Activity，遵守 [Android 通知跳转约束](https://developer.android.com/about/versions/12/behavior-changes-12#notification-trampolines)，不经广播或服务调起界面。

## 导入与并发保护

文件导入先选文件、识别/映射、预览再确认；教务导入先核对开学日期，再预览课程和作息。选文件、取消或仅展开预览均不修改已保存课表。多工作表选择和已应用映射在重新预览时保留，不能无声改用另一份源数据。

保存时检查编辑基线；其他页面或窗口已修改目标时拒绝旧内容覆盖，并保留草稿供核对。完整备份恢复比较的是整个应用数据，防止覆盖读取备份后新改的教材或外观。

数据事务见 [架构](architecture.md)，格式与撤销见 [数据说明](data-and-migration.md)，测试入口见 [开发说明](development.md)。设备触摸、返回、键盘与系统取消必须以实际设备测试为准。
