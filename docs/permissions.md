# Android 权限与数据访问

当前源码 Manifest 声明以下五项系统权限；后两项随未发布的周期教务检查加入。权限以实际合并 Manifest 为准，工程检查会核对允许列表；第一次引导不批量申请授权。

| 权限 | 用途 | 触发方式 |
|---|---|---|
| `INTERNET` | 用户打开学校教务页，以及读取本项目 GitHub 正式 Release 元数据 | 普通声明权限，不弹运行时授权框 |
| `POST_NOTIFICATIONS` | 用户主动开始地图导航后的行程通知 | Android 13+ 在开启导航行程或开始需要通知的导航时申请；拒绝后地图仍可打开 |
| `POST_PROMOTED_NOTIFICATIONS` | 向 Android 16+ 请求符合条件的行程实时活动展示 | 声明权限；实际提升由系统和通知设置决定 |
| `ACCESS_NETWORK_STATE` | 系统仅在有网络时安排教务检查 | 普通声明权限，不弹授权框 |
| `RECEIVE_BOOT_COMPLETED` | 允许 JobScheduler 在重启后保留用户启用的周期教务任务 | 普通声明权限；应用不注册开机广播，不在开机时弹页面 |

应用不再申请读写系统日历权限，也不调度课前提醒。没有精确闹钟、应用开机广播接收器、后台弹出、悬浮窗、电池优化豁免、通讯录、定位、安装应用或广泛存储权限。

## 文件、图片和相机

导入、完整备份与模板导出使用系统文档选择器，只读取或写入用户所选位置。教材封面和自选背景通过系统选图获得内容 URI，不扫描照片库，不申请照片库读取权限。

拍摄教材封面调用系统相机应用，并通过 `FileProvider` 临时分享本次输出文件的 URI；应用不直接接管相机设备，不声明 `CAMERA` 权限。用户取消或返回时保留原封面。

导航由用户点击后交给外部高德、百度地图或能处理链接的应用。搜索地址仅使用学校与楼栋，不需要 Dolphin 获取设备定位；地图应用自身的权限由它独立管理。

“复制给 AI 的整理提示词”仅在用户点击时写入剪贴板，不读取剪贴板，也不会调用外部 AI 服务。文件或截图是否分享给其他工具，由用户决定。

## 网络与登录

教务浏览器只允许已适配学校和统一认证的 HTTPS 地址，登录信息由学校页面处理。用户可选择在本机记住站点会话，或退出后清理；会话不进入课表数据库或导出备份。证书错误不能通过忽略验证继续访问。

周期教务检查默认关闭，需完成首次教务导入并选择记住登录。无界面 WebView 复用同一隔离会话，触发本校原有课表查询；仅放行 GET/HEAD 和已验证的课表只读 POST，拒绝其他提交，不读取密码或令牌。用户打开教务浏览时停止后台读取。JobService 由系统 `BIND_JOB_SERVICE` 权限保护，不启动前台服务或新系统通知；省电、断网、强行停止应用可能延后或停止任务。

更新页访问本仓库 GitHub Release 接口，下载按钮打开浏览器。应用不使用后台更新任务、内置 APK 下载器或自动安装；课表、教材和背景不上传到 GitHub。

## 系统行程展示

导航行程最长 30 分钟，以非精确闹钟辅助收起。系统省电可能延迟回调，下次进入应用时会重新核对期限并撤下过期行程；设备重启后不自动恢复。通知关闭不影响本地课表和地图导航。

AndroidX 可能在合并 Manifest 中生成以应用包名开头的内部 `signature` 权限，用于保护动态接收器。它不是额外的用户运行时授权，也不提供自启动能力。

数据范围见 [数据与迁移](data-and-migration.md)，行程展示边界见 [通知说明](notifications.md)，验证方法见 [开发说明](development.md)。
