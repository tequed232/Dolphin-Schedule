# 导航行程与灵动岛

本版通知只保留**用户主动导航后的行程**。课前提醒、提前量、测试提醒、桌宠、戳一下和台词管理均已移除，不会在空闲时常驻通知。

## 使用流程

1. 在“设置 → 导航与学校”填写学校名称，选择高德或百度地图。
2. 在课程详情或主页导航按钮中主动开始课程导航。
3. 应用核对课程与目标后打开外部地图。地图成功打开、通知开关开启且系统允许通知时，才创建行程。
4. 点击行程中的“我到了”，或在“设置 → 实时通知”结束当前行程。结束操作直接收起通知，不补发到达消息。

课程入口和卡片的目的地按钮均优先打开本地高德；客户端未安装或调起被系统拒绝时回退网页，百度保持网页入口。当前按学校与楼栋搜索，需在地图中核对地点并开始路线；不增加地图 SDK 或定位权限。通知目的地按钮会重新校验当前行程的令牌、期限及目标，旧通知不能打开新行程目标，也不会因点击而延长期限。具体规则见 [打开地图](navigation.md#打开地图)。

拒绝通知权限仍可打开地图。学校或教室信息不足、课程已变化、地图无法打开时会提示原因，不生成虚假行程。地图仅搜索学校与楼栋，完整教室号保留在课表和通知中。

## 行程生命周期

每段行程有独立令牌，最长持续 30 分钟。同一目标的重复导航以及反复回到 App 不延长原期限；旧通知的到达、删除或超时操作不能结束后来启动的行程。

关闭行程开关、课程删除或导航目标变化后，应用会撤下失效行程。返回应用、应用更新以及超时回调都会重新核对状态，不在后台重建已经结束的行程。超时回调使用系统允许的非精确闹钟，省电策略可能造成延迟；设备重启后不会自动恢复。

升级时清理旧提醒闹钟、旧通知渠道和桌宠状态。旧版备份中的提醒、桌宠和台词偏好不会重新启用这些功能。

## 系统展示边界

Android 16+ 可为符合条件的行程请求标准实时活动展示；其他受支持的 Android 版本使用普通行程通知。应用通过系统返回的资格和提升状态判断结果，只有系统实际设置提升标记时才显示“已提升”。

灵动岛、锁屏卡片、状态栏提示、封面及按钮最终由设备系统布局。Android 标准请求不等于已经接入所有厂商的专用灵动岛模板，不能保证每款手机都采用同样样式。当前课程行程的实际状态可在“设置 → 实时通知 → 查看当前行程状态”中检查，Android 16+ 另提供系统实时活动设置入口。

未显示时，依次检查应用内导航行程开关、系统通知权限与渠道、系统实时活动设置及设备省电状态。历史设备测试结果不能替代当前版本、当前设备的实际验收。

权限见 [权限说明](permissions.md)，状态和令牌边界见 [架构说明](architecture.md)，隔离测试规则见 [开发说明](development.md)。

## 展开卡片内容

卡片按“课程名 → 正在前往教室 → 教材”显示，使用加粗文字和右侧品牌图；未填写教材时不显示占位文本。底部保留“去完整教室地址”和“我到了”两个操作。折叠胶囊继续使用短楼栋名，不显示虚构的到达时间或进度。

教务的明确数字地点如 `1-401 (QY1-401)` 显示为“1栋401号教室”，收起胶囊显示“1栋”。不明确的地点保留原文，不猜测楼栋；地图实际目标保持原有导航规则。ColorOS 已显示右上品牌图时，不再附加左侧重复大图；其他系统仍提供标准大图标。

2026-10-27 的 RMX6688 真机验收已确认系统设置 `PROMOTED_ONGOING`、顶部胶囊出现，且“我到了”可撤下行程；通知栏显示双按钮卡片。该记录不代表其他厂商已验收，也不代表厂商胶囊长按的展开行为与标准通知栏一致。

使用标准 BigTextStyle，不添加自定义 RemoteViews 或彩色背景，保留 Android 实时活动资格。毛玻璃、圆角、字号与按钮最终外形由系统决定，不能承诺与参考截图逐像素一致。[Android 标准实时活动要求](https://developer.android.com/develop/ui/views/notifications/live-update)。

安装升级会结束旧行程，避免旧接收器按钮失效；再次主动导航即可创建新行程，课程、教材与登录状态不受影响。

2026-10-27 在 RMX6688 真机安装当前正式签名验收包后，课程入口和通知目的地按钮均通过系统事件确认启动本地高德的 `SchemeHandleActivity`；该记录验证客户端调起，不代表校内楼栋收录、路线或到达位置已验证。模拟器另覆盖客户端不可用时的网页回退，以及旧通知按钮不能打开后来行程的目标。
