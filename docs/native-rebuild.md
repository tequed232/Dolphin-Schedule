# 1.6.0 原生功能范围与验收

本版以 Kotlin＋Jetpack Compose 作为正式应用入口，保留原有课表视觉风格和悬浮胶囊。根目录旧网页实现、旧宿主、React/Vite/TypeScript 依赖和独立网页发布不属于应用架构。

## 保留范围

| 功能 | 当前产品范围 |
|---|---|
| 首次使用 | 本地数据说明、导入、手动添加、先进入课表；持久化完成状态，不填演示数据 |
| 列表与平铺 | 日期条、月历、下一节课、搜索、课程块、午休收起、当前时间线与浮动胶囊 |
| 课程管理 | 增删改、复杂周次、指定日期课程、长按移动、上下把手、冲突确认及取消保护 |
| 作息 | 修改名称和起止时间、删除未占用节次并重排索引、添加节次 |
| 教务导入 | App 内登录、地址编辑、逐节识别、日期优先、预览、确认替换、撤销、选择记住登录 |
| 文件导入 | JSON / CSV / XLS / XLSX、工作表选择、映射、错误明细和确认保存 |
| 教材 | 本地文字、相册或系统相机封面、同名课程关联 |
| 外观 | 深浅模式、动态取色、字体、自选背景、模糊、安全区和性能模式 |
| 导航 | 学校与高德/百度选择、课程主动导航、导航后行程通知 |
| 数据 | SQLite 事务、同包旧数据一次性迁移、完整备份和恢复 |
| 更新 | 读取 GitHub 正式 Release，版本与说明，浏览器下载；不调度后台更新 |
| 关于 | 作者、版本、项目入口、重新看引导、离线 MIT 和第三方许可 |

## 已决定移除

系统日历同步、节假日来源与标记、课前提醒、提前量、通知桌宠、戳一下、台词管理、第三方插件扩展、电脑模式/屏幕方向切换按钮、内置背景图、独立 Web 与 Pages/PWA 发布。

教务定时刷新、更多学校和导入时合并手动课程不在本轮范围。当前保留替换与撤销，不自动合并。

## 验收规则

- 构建、JUnit、Compose 设备测试与 lint 分别提供实际结果；工程不变量检查不能代替业务或设备验证。
- 课程点击、普通横滑、边缘翻周、长按移动和把手调整互不抢占；返回与系统取消不提交预览。
- 午休收起不删除学校原始节次，删除空闲节次不改变后续课程实际时间；当前时间线仅在正确日期范围出现。
- 升级先保存旧数据原文，再写入 SQLite；迁移失败保留数据并可重试，不退化成空课表。
- 教务和文件确认前不写入，过期预览不能覆盖新课表；完整备份包括教材和背景，排除登录会话。
- 主动导航成功后才创建行程；拒绝通知仍可打开地图。灵动岛、实时活动和厂商展示必须以当前设备证据确认，不宣称所有设备已通过。
- 正式发行核对包名、版本、签名、附件 SHA256 与仓库源码提交；GitHub 发布是否完成以远端实际状态为准。

合成数据测试仅在明确指定的隔离模拟器运行。真实设备的课程、教材、登录状态和既有安装包不因测试被清除或替换。证据保存在忽略的 `build/evidence/`，不随源码上传。

详细实现见 [架构](architecture.md)，验证与交付见 [开发](development.md) 和 [发布](release.md)。
