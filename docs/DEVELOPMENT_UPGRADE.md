# 开发与数据流程

项目由 React / TypeScript 网页和 Kotlin Android 宿主组成，共用同一份网页构建。没有独立业务服务器；课表和偏好保存在设备的 IndexedDB，Android 通过受限消息桥接收提醒、通知与系统日历所需的数据。

## 目录与职责

| 路径 | 职责 |
|---|---|
| `web/src/components` | 课程、教材、导入预览、日期选择等共享界面 |
| `web/src/screens` | 列表、平铺、搜索、设置和二级任务页面 |
| `web/src/lib` | 数据模型、解析、迁移、存储事务和原生桥 |
| `web/src/state` | 应用状态、插件状态、自动保存和异步读取 |
| `web/src/nav` | 页面栈、返回和一级导航 |
| `web/src/theme` | 布局、主题、安全区与动效 |
| `app/src/main` | WebView 宿主、提醒、通知、系统日历和 Android 资源 |
| `app/src/test` | 原生纯逻辑单元测试 |
| `scripts` | 构建工具、可复用测试、文件准入与打包脚本 |
| `docs` | 用户指南、公开接口、维护约定与发布流程 |

## 数据与保存

`Schedule.periods.length` 是唯一课程节数来源，支持 1–24 节；显式上下课时间保存在 `periods`。课表管理、主页、搜索、课程编辑和提醒共用同一份 Schedule。

所有应用编辑通过 `AppState.update` 队列，在一个 IndexedDB 事务中读取版本与最新状态并修改。事务成功后才更新 React 状态和原生镜像，再通知其他窗口。课表与插件状态使用各自数据库；更新缓存使用独立键。正常保存只需读取版本号，变化分支之外的对象引用保持稳定。

学校名称和台词使用即时草稿、合并保存及中文组合输入保护。保存失败保留输入并允许重试；离开页面时处理未保存草稿。

课程、教材、课表配置和导入预览记录编辑基线。保存事务检查相关字段是否已被其他窗口修改，冲突时保留草稿并明确提示。重新读取需用户确认；上课时间页面只提交时间字段。导入重新预览保留源文件、工作表、已应用的手动映射和确认的日期。

## 导入与兼容

JSON / CSV / XLS / XLSX 共用现有解析、预览和确认流程。正常单表自动进入预览；多工作表、手动映射或错误明细在读取页面处理。解析失败不写入课表；最终确认才提交数据。

JSON 支持 `term` / `semester`、`schedule` / `data` / `result` 包裹及旧字段别名。支持明确的 `times` / `periodTimes` / `periods` 时间表，也支持 `courseCount`、`firstStart`、`duration`、`breakMinutes`。`times.index` 从 1 连续且不重复。时间重叠、倒序和不完整配置会报错。

缺少学期或时间配置时沿用当前值。文件仅提供有效配置而没有课程数组时，只更新配置并保留课程与 ID。JSON 导出恢复原课程 ID、隐藏课节和指定日期；课程 JSON 不包含全部教材、背景与偏好。

周次支持分段范围与单双周；指定日期课程按该日期计算。增加节次保留已有时间，减少有课节次需确认；超出节数的课程保留，增加节数后恢复显示和提醒。自动生成的作息不跨午夜，午休等休息单独保存。

格式与用户操作见 [导入指南](IMPORT_GUIDE.md)，插件转换器的接口见 [插件文档](PLUGINS.md)。

## 导航与展示

列表 / 平铺 / 搜索 / 设置是独立一级导航。列表和平铺共用日期、课程与节次焦点；切换保留语义位置，退出布局编辑。点击课程查看详情，长按或明确操作进入布局编辑；返回、切页和点击空白结束编辑。

Android 使用 WebView 外的原生导航，网页使用对应底栏或侧栏。竖屏导航置底，横屏和宽屏置于侧边。二级任务、对话框和键盘显示时处理导航与安全区，弹窗不继承页面缩放。

日期展示、周课程和冲突分列按输入对象缓存；滚动采样合并到动画帧，非活动课表停止时钟。减少动态效果偏好同时覆盖元素与伪元素；详情动画遵守系统偏好。

## 原生与更新

原生消息仅接受指定应用来源和主框架。插件运行在隔离 iframe 中，按权限提供快照与操作；不直接获得数据库、宿主 DOM 或原生对象。公开接口见 [插件文档](PLUGINS.md)。

提醒按当前课程、开关、课次时间与批次 token 校验。重复同步同一待触发课次保留原批次；取消、改期或关闭后旧回调不再生效。系统日历操作只管理应用自己的课程日历，复原保留原日历及可见性。

网页更新只读取本仓库官方正式 Release；排除 draft、prerelease 和不匹配的下载地址。实时结果不被迟到缓存覆盖。网页使用联网优先、离线回退的首页缓存；Android 使用内置资源，不启用网页 Service Worker。

## 本地检查

运行 `npm run build`、`npm run check` 和 `node scripts/ci.mjs`。完整浏览器回归自行启动开发服务。Android 使用 `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`。

测试源码可以入库；运行日志、截图、报告、备份和本机配置只保存在被忽略的本地目录。实体设备的通知样式、ROM 调度和帧率应在对应设备测量。发布入口见 [发布说明](PUBLISHING.md)。
