# 课表导航与导入交互

列表、平铺、搜索和设置是独立一级导航。列表和平铺共用 Schedule 与日期、课程、节次焦点，不各自保存一份课表。竖屏使用底栏，横屏和宽屏使用侧栏。

| 操作 | 行为规则 |
|---|---|
| 选择日期或切换周 | 当前日期与自然周分别计算；日期条的周末偏好不删除平铺中的课程 |
| 切换列表和平铺 | 保留所看日期和课程的语义位置，退出布局编辑；不直接复制像素偏移 |
| 点击、长按课程 | 点击查看详情，长按或明确操作进入编辑；只有当前课程显示调整把手 |
| 拖动与调整课节 | 主体改变位置，纵向把手改变起止节次；范围合法且至少一节，冲突由用户确认 |
| 返回或取消 | 优先处理选项菜单、弹窗、草稿和编辑状态，再返回上一级；取消不写入数据 |
| 二级任务 | 隐藏一级导航，保留顶部返回；完成后回到发起任务的位置 |
| 文件导入 | 选择文件、自动识别、解析校验、预览变更、确认导入；确认前不更改课表 |
| 格式不符 | 显示具体错误并允许明确指定格式，正常文件不重复要求选择格式 |
| 多表与映射 | 保留已选工作表和已应用的手动映射，重新预览不静默切换源数据 |
| 缺省导入配置 | 沿用当前学期和未提供的作息；预览说明修改与保留的内容 |
| 多窗口修改 | 保存时检查目标的编辑基线，保留冲突草稿；重新读取前确认放弃当前输入 |
| 当前时间更新 | 不抢回用户主动浏览的位置；重复点击当前一级导航不重置焦点 |
| 布局与安全区 | 内容、导航、键盘和弹层分别占位，末节课程与确认按钮能够滚入可视区 |

业务状态与保存事务见 [开发说明](DEVELOPMENT_UPGRADE.md)，具体导入格式见 [导入指南](IMPORT_GUIDE.md)。
