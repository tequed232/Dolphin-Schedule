# 学校教务导入方案与边界

当前源码已经接入 App 内手动识别、原生预览、确认替换、撤销和登录保留选择。未发布源码增加周期检查、持久待确认结果及可选保留手动课程；首版仅适配广东财贸职业学院，不扩展更多学校。课表变化仅在 App 内提示，系统通知继续只保留主动导航后的行程。发布状态以 GitHub Releases 为准，实际登录与识别兼容性以当前学校页面和目标设备测试为准。

学校入口：[个人学期课表](https://jwxt.gdcmxy.edu.cn:1004/#/jwxt/js/student/personal/studentSchedule)。

## 方案选择

| 方案 | 适用方式 | 当前选择 |
|---|---|---|
| App 专用 WebView | 用户自行登录、选学期、点击识别，再回原生页核对 | 主流程；符合 App 内一键识别需求 |
| 外部浏览器与文件 | 用户在学校系统导出文件，再回 App 导入 | 页面或登录不兼容时的回退方式，取决于学校导出格式 |

系统浏览器与 App WebView 会话彼此独立，不能靠打开浏览器直接读取任意已登录页面。App 不接管密码或验证码，不使用代登录服务器、云账号、OCR 或外部 AI 识别。

## 用户流程

1. 从导入页打开教务浏览器。顶部提供返回、可编辑地址和刷新；仅接受已适配的 HTTPS 教务及统一认证地址。
2. 自行登录，进入个人学期课表，选择从第 1 周开始的完整学期范围，取消“大节次”后查询。
3. 按需勾选“记住登录 · 仅此设备”，点击“识别课表”。低频说明收在帮助中，没有电脑模式或方向切换按钮。
4. 回到原生预览，先核对开学日期；没有可靠日期时先设置日期再生成课程预览。
5. 展开需要核对的逐节作息和课程，检查新增/移除数量、地点、教师及周次，勾选确认后替换当前课表。
6. 需要时选择“撤销上次教务导入”，预览后恢复导入前课表。导入后的手动课程修改也会被替换，教材、背景和偏好保留。

确认前不写入。预览恢复或本地课表发生变化后必须重新核对；旧草稿不能直接覆盖最新课表。

## 读取与标准化

提取脚本按学校页面结构读取可见完整表格，区分隐藏打印副本、星期表头、时间轴、课程、教师、班级与地点。不以非空格子的顺序猜星期，不通过课名去掉合法的同名课程。

| 项目 | 当前规则 |
|---|---|
| 学期 | 识别所选学期和查询周范围，拒绝从中间周开始的局部课表 |
| 日期 | 同源学期接口返回有效日期且学期匹配时采用，否则要求用户确认 |
| 节次 | 每行必须有名称及起止时间，按完整时间轴确定数量，最多 24 节 |
| 中午时段 | 保留“中午1”等学校名称与实际数组位置；显示时只收起无课程占用的午休占位 |
| 周次 | 展开 `4;6-9;12-18`、单周、双周等表达，拒绝非法范围 |
| 连堂课程 | 仅在名称、教师、地点、星期及周次一致、原始节次确实相邻时合并 |
| 地点 | `--` 等缺失标记转为空，保留课程并提示补充 |
| 标识 | 完整内容相同尽量沿用现有课程 ID；新课程使用稳定内容标识并检查冲突 |
| 差异 | 显示新增、移除和可唯一对应的修改；明细对照课程字段、学期名称/周数/日期及逐节作息。未发布变更见版本记录 |

开学日期读取使用 `/api/baseInfo/semester/selectCurrentXnXq` 提供的 `semester` 与 `ksrq`。接口失败、超时、日期无效或与当前选择学期不符时，不把当前学期日期套给历史课表，也不根据学期标题推算日期。日期所在周的周一计为第 1 周。学校可能改版，该接口不能作为永久契约。

只接受可判断加载完成的个人学期课表。多份可见主体、缺失星期列、时间轴异常、课程字段不完整、超限或空课表会停止识别，保留原课表。提取结果上限 700,000 字节、2000 个课程块，普通节次和中午节次分别验证学校编号连续性。

## 登录与 WebView

浏览页仅允许 `https://jwxt.gdcmxy.edu.cn:1004` 与 `https://sso.gdcmxy.edu.cn`（默认 HTTPS 端口或 443）。编辑地址不会扩展允许范围；证书失败停止连接。学校页面没有 Dolphin 业务能力桥，结果通过私有文件与请求标识交给原生页校验。

会话优先使用 AndroidX WebKit 独立 Profile；缺少多 Profile 能力且 Android 版本不低于 9.0 时，使用 `:academic_legacy` 专用进程和独立数据目录。两条路径的登录状态彼此独立。勾选记住登录仅在本机保留站点会话，不主动读取或保存密码；清理针对当前路径的教务 Cookie 与站点存储，不删除默认 Profile 的旧课表库。多 Profile 路径只清理 `dolphin-academic-` 前缀配置，被 WebView 引擎占用的目录延迟到后续进程删除。

设备 WebView 不支持 `MULTI_PROFILE` 时，Android 9.0 及以上走独立进程兼容路径；Android 8.x 明确提示更新，保留文件导入入口，不退回共享登录配置。兼容路径在任何 WebKit 调用前设置数据目录后缀。“WebView 不可用”需要核对设备组件支持与初始化阶段；不能靠更换 Kotlin 语法或忽略证书验证解决。

版本验收记录见 [README 的 WebView 兼容性表](../README.md#内置教务导入的-webview-兼容性)：`154.0.8037.57` 已于 2026-10-27 在 RMX6688 上复验网页加载、登录保留和真实课表识别预览；`114.0.5.302` 的旧内核兼容修复仍待该确切版本验收，不能视为已支持，也不能由两个样本推导统一最低内核版本。

## 数据与实现位置

| 路径（相对应用源码） | 作用 |
|---|---|
| `academic/AcademicActivity.kt` | 地址、登录、学校页面、提取与私有结果回传 |
| `academic/AcademicPolicy.kt` | HTTPS、主机、端口、课表路径与请求标识限制 |
| `academic/AcademicProfileCleanup.kt` | 教务会话清理与占用目录延后删除 |
| `academic/LegacyAcademicActivity.kt` | Android 9+ 的旧内核专用进程与独立 WebView 数据目录 |
| `assets/academic/extract.js` | 构建内置的学校页面读取脚本 |
| `domain/AcademicImporter.kt` | Kotlin 转换、校验、稳定 ID、差异及撤销 |
| `domain/ScheduleDifference.kt` | 不修改源数据的课程匹配、变化字段和逐节作息比较 |
| `ui/importing/ScheduleDifferencePreview.kt` | 教务、文件及撤销共用的只读明细，长列表按需显示 |
| `data/AcademicCodec.kt` / `AcademicDraftStore.kt` | 结果解码、私有草稿和编辑基线 |
| `ui/importing/NativeImportScreen.kt` / `ui/DolphinViewModel.kt` | 日期优先预览、确认、返回与事务接线 |

表中 Kotlin 路径相对 `app/src/main/kotlin/com/dolphin/schedule/`，资源路径相对 `app/src/main/`。这是内部学校适配结构，不提供第三方插件注册、远程脚本加载或插件市场。

导入新课表和前后快照在同一 SQLite 事务保存。撤销仅保留最近一次，不能代替完整备份。草稿存在应用私有目录；Activity 状态保存标识，不塞入整份结果或图片。

## 后续设想与验收

差异明细先匹配完整内容，忽略课程 ID 与周次顺序；再按唯一稳定 ID、同学期的唯一课程位置或剩余唯一名称建立前后对照。含糊同名记录不猜测为修改，仍显示新增/移除。备注、临时标记和颜色的变化也会列出，防止替换时丢失手动内容却不提醒。明细只读，不改变原有确认、过期预览保护或事务撤销逻辑。

2026-10-30 在 RMX6688 上重新登录学校系统，查询完整学期并切换逐节模式后，完成真实识别与新增明细的只读预览；返回时仍显示放弃确认，继续核对保留结果，未勾选确认时保存按钮禁用。没有确认导入或恢复，不把预览验证记为再次写入成功。

未发布源码已接入持久候选、可选保留课程及默认关闭的周期检查。学校原页面的 `/api/arrange/CourseScheduleAllQuery/studentCourseSchedule` 为已核对的只读 POST；后台阻止其他非 GET/HEAD 请求，等待查询完成后使用同一提取器校验。复用用户选择记住的 Profile 或旧内核独立目录，不自行读取登录令牌、不处理验证码、不后台选择其他学期。用户打开教务浏览时停止后台读取。

`AcademicCheckScheduler` 通过 JobScheduler 安排 6/12/24 小时检查，要求网络和非低电量；`AcademicCheckJobService` 只在系统授权下运行，旧内核使用同一隔离进程。`AcademicCheckRunner` 重新检查课表基线、候选 ID、导入历史及周期开关后才保存结果。候选入库并广播本包数据修订，主页面重载；不创建新系统通知，不自动替换课程。已有候选暂停周期读取，用户可立即复查；登录失效暂停周期触网。

来源与合并由 `domain/AcademicMerge.kt` 处理，准确时间无法映射或学期不一致时拒绝合并；冲突需额外确认。候选及基线随 SQLite 私有快照保存，不进入完整备份。恢复、放弃、重建预览和确认均清除上次勾选，不补交未确认写入。

2026-10-30 在 RMX6688 / Android System WebView `156.0.8078.47` 保留数据安装后找回旧候选；用户确认导入后，立即检查在无教务 Activity 的情况下复用登录并返回无变化。系统 6 小时任务注册与取消通过；尚未做跨日周期观察。精确华为 114 环境仍不在已通过名单。分阶段清单见 [功能范围与待办](native-rebuild.md#分阶段补齐)。

当前测试包括学校 URL 边界、合成页面提取的拒绝路径、Kotlin 复杂周次与特殊节次、动态作息、稳定 ID、预览保护和事务撤销。模拟结果不代替真实账号登录、验证码、学校网络与设备 Cookie 清理测试。验收时确认取消不写入、日期无法读取有明确路径、教务改版不覆盖原课表、教材和外观保留，且真实姓名、学号、Cookie、令牌与私人课表不进入源码或公开证据。

构建与测试入口见 [开发说明](development.md)，完整备份和迁移见 [数据说明](data-and-migration.md)。
