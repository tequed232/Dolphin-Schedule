# 数据格式与旧版迁移

## 新 App 身份

正式包为 `com.dolphin.schedule`，调试包为 `com.dolphin.schedule.debug`；IndexedDB 名为 `dolphin-schedule`。更名前后的 App 由 Android 分别管理，可以并存。相同签名也不能跨包名覆盖安装。

迁移方法：

1. 在旧 App 导出课表 JSON，并保留旧 App 直至迁移完成。
2. 安装 Dolphin Schedule，在导入页选择 JSON 文件。
3. 预览学期开始日期、周数、节次和课程数量，确认后导入。
4. 在新版重新设置教材封面、背景、学校、提醒和系统权限。

课表 JSON 包含学期、课程和节次，不包含全部偏好、教材封面或背景。此轮不提供跨包名自动读取或迁移私有数据库。调试包、正式包和浏览器调试数据也彼此独立。卸载或清除数据会删除本地内容。

旧 App 已创建的系统日历属于旧包，新 App 不会接管或删除它；如需避免重复显示，请先在旧 App 清除其课程日历，再从新版导入。

## JSON 示例

```json
{
  "term": {"name": "2026–2027 秋季学期", "startDate": "2026-09-01", "weeks": 20},
  "courses": [
    {
      "name": "线性代数", "teacher": "示例教师", "room": "16栋203号教室",
      "day": 1, "start": 1, "end": 2, "weeks": [1, 2, 3, 4, 5, 6],
      "color": "sage", "notes": "请携带教材"
    }
  ]
}
```

| 字段 | 含义 |
|---|---|
| `term.startDate` | 开学日期，YYYY-MM-DD；第 1 周从该日期所在周的周一计算 |
| `term.weeks` | 总周数，1–999 |
| `courses[].day` | 周一为 1，周日为 7 |
| `start` / `end` | 连续开始/结束节次，按节次表计算 |
| `weeks` | 实际上课周次，单双周应展开 |
| `room` | 完整楼栋和教室，不带学校名；不确定时保留原文 |
| `teacher` / `notes` | 教师和备注，不确定时可留空 |
| `color` | 可选 sage、lavender、peach、blue、rose |

可提供 `periods` 数组，例如 `[{"start":"08:00","end":"08:45"},{"start":"08:55","end":"09:40"}]`。不提供时沿用当前节次表，新安装默认 12 节。最多 24 节，时间使用 24 小时制，起止必须有效且节次之间不重叠。

## 兼容与限制

支持旧版 JSON 字段别名、二维课程形状和 JSON 围栏文本。未提供开学日期时优先从学期名取年份并暂定 9 月 1 日；未提供总周数时从课程推断，无法推断则暂定 52 周，预览提示核对。更晚课程周次会扩展学期；缺少周次按最终学期每周上课处理。

- 文件上限 5 MB，文本上限 5,000,000 字符。
- 最多 2,000 条课程、999 周，合计不超过 20,000 次上课。
- 预览最多列出前 8 门，同时显示总数；导入仍包含完整课表。
- 错误日期、空表、倒序节次、过大数据应报错并保留当前课表。
- 保存成功后才更新界面与原生镜像；取消预览不覆盖当前数据。

导入入口接受 JSON、CSV、XLS 和 XLSX。图片和教务网页应先通过外部工具转换；完整 JSON 转换提示词和逐节作息格式说明保留在 App 中。旧网页教程与演示视频已移除。测试专用示例位于 `tests/fixtures/`，App 不再提供演示课表入口。

## 1.5.1 完整文件导入

JSON、CSV 和 Excel 共用预览与确认流程。JSON 可恢复课程和学期配置；CSV/Excel 支持课程、逐节起止时间、午休和仅时间更新，缺失的学期配置沿用当前课表。CSV 支持 UTF-8、UTF-16 BOM 与 GB18030，解析器会拒绝冲突、重叠或倒序的时间。下载模板属于格式说明，示例内容不会自动写入课表。

编辑预览保存前会检查课表版本；其他窗口修改后需重新预览，避免旧草稿覆盖新数据。列表、平铺和搜索始终使用同一份课表。
