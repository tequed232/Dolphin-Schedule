# 数据、导入与迁移

## 本地数据与应用身份

正式包为 `com.dolphin.schedule`，调试包为 `com.dolphin.schedule.debug`。当前原生数据保存在应用私有 SQLite 数据库 `dolphin-native.db`；课程、教材、背景、偏好和最近一次教务撤销记录组成一份事务快照。登录会话与课表隔离，不进入完整备份。

不同包名由 Android 分别管理，不能互相读取私有数据库；更名前的旧包、正式包、调试包、独立验收包和浏览器站点数据彼此独立。卸载或清除数据会删除应用本地内容，升级前和换设备前应先导出备份。

## 同包旧版本升级

同包、同发行签名升级时，如果 SQLite 尚无记录，应用会尝试只读访问旧本地来源的 IndexedDB `dolphin-schedule`，保存旧数据原文到私有迁移备份，再将校验后的数据写入 SQLite。迁移不加载旧业务网页、不请求网络、不删除旧库。读取或保存失败会保留旧数据并提供重试，不自动创建空课表覆盖。全新安装没有旧 WebView 目录时直接初始化原生数据。

迁移保留仍受支持的课表、教材、背景和偏好；旧提醒、桌宠、台词、节假日等退役字段不再写入或恢复。SQLite 已存在后不反复从旧库覆盖新数据。不要在不同安装包或历史入口间交替编辑并期望自动同步。

更名前的旧包无法直接覆盖：在旧 App 导出课表 JSON，保留旧包直至完成核对，再在新版文件导入页预览并确认。课表 JSON 只能转移它实际包含的学期、课程和作息；旧包未导出的教材或背景需重新设置。旧版创建的系统日历不由新版接管或删除，需要时在旧包或系统日历中自行清理。

## 完整备份与恢复

“设置 → 数据与备份”提供“导出完整备份”和“从备份恢复”。完整 JSON 包含课表、教材文字和封面、自选背景、受支持偏好、引导状态及最近一次教务导入前后快照，最大 **16 MB**。教务 Cookie、密码、会话和当前导航行程不在其中。

恢复前先导出当前备份，选择文件后核对学期和课程/教材数量，再确认替换。确认前不会写入；如果读取后当前应用数据已变化，旧预览会被拒绝，需重新选择并核对。损坏、超限或不支持的备份保留当前数据。完整备份和普通课表文件用途不同，应从各自入口使用。

## 文件导入

主页导入和设置中的“导入课表”入口支持 **JSON、CSV、XLS、XLSX**，也可粘贴 JSON。流程为选文件、识别格式/工作表、必要时调整字段映射、预览配置与课程、确认保存。列表、平铺与搜索始终读取同一份已提交课表。

缺少开学日期或学期周数时，会说明沿用或推断的配置，须在保存前核对。只有时间配置的文件保留课程及课程 ID；完整覆盖第 1～N 节的作息可确定总节数，部分时间只更新提供的节次。连堂总时间只能确定首尾，不据此编造中间上下课时刻。

课程行错误会展示具体明细；部分可解析时会明确提示跳过项，确认前应检查课程总数。空表、无有效课程/作息、非法日期、倒序或重叠时间不会静默覆盖。多窗口修改后，旧草稿不能直接覆盖新课表。

## JSON 格式示例

```json
{
  "term": {"name": "2026–2027 秋季学期", "startDate": "2026-09-01", "weeks": 20},
  "periods": [
    {"start": "08:30", "end": "09:10", "label": "1"},
    {"start": "09:15", "end": "09:55", "label": "2"}
  ],
  "courses": [
    {
      "name": "线性代数", "teacher": "示例教师", "room": "16栋203号教室",
      "day": 1, "start": 1, "end": 2, "weeks": [1, 2, 3, 4, 5, 6],
      "color": "sage", "notes": "请携带教材"
    }
  ]
}
```

| 字段 | 含义 |
|---|---|
| `term.startDate` | `YYYY-MM-DD`；该日期所在周的周一计为第 1 周 |
| `term.weeks` | 学期周数，1～999 |
| `periods` | 按时间顺序排列的逐节作息，最多 24 节；缺少时沿用当前配置 |
| `periods[].label` | 可选节次显示名称，不代替数组位置 |
| `courses[].day` | 周一为 1，周日为 7 |
| `start` / `end` | `periods` 中从 1 开始的连续起止位置 |
| `weeks` | 实际上课周数组；单双周展开成明确数字 |
| `room` / `teacher` / `notes` | 地点、教师和备注；不确定时留空或保留待核对原文 |
| `color` | 可选 `sage`、`lavender`、`peach`、`blue`、`rose` |
| `specificDate` | 可选指定日期 `YYYY-MM-DD`，用于临时课程 |

支持常见旧字段别名、二维课程形状和 JSON 围栏文本。标准课表备份带有课程 ID 时尽量保留原标识；普通导入会生成新的标识。课程中更晚的周次可扩展普通导入的学期，缺省周次按最终学期每周处理，应核对预览说明。模板位于“模板与导入帮助”，带当前日期和作息及一条示例课程，必须替换后使用；模板不会自动填入课表。

CSV 支持 UTF-8、UTF-16 BOM 与 GB18030。Excel 在本机受限 WebView 中解码单元格，不上传文件、不执行工作簿宏；课程解析与保存由 Kotlin 处理。

| 限制 | 上限 |
|---|---|
| 普通导入文件 | 5,000,000 字节 |
| 表格 | 每表 3000 行、100 列 |
| 普通导入课程 | 2000 条，合计不超过 20,000 次上课 |
| Excel 解压与单元格 | 64 MB、30 万单元格 |
| 作息与周次 | 最多 24 节、999 周 |

## 学校教务导入

首版适配 `jwxt.gdcmxy.edu.cn:1004`。在 App 专用浏览页自行登录，选择完整学期范围，关闭“大节次”并查询，再点击“识别课表”。总节数来自实际完整时间轴，保留学校显示名称；未占课程的午休占位可在课表显示时收起，不删除源节次。

开学日期始终在预览最前。只有同学期、有效的教务开始日期才自动采用；接口不可用或学期不匹配时先手动确认日期，随后核对课程、周次、教师、地点和逐节作息。勾选确认后才替换，不自动合并手动课程。页面结构变化、异常空课表或不完整作息会阻止导入。

替换和导入前快照在同一事务保存，可“撤销上次教务导入”；撤销会替换导入后手动修改的课表，确认前再次核对。教材、背景和偏好保留。只保留最近一次撤销快照，不能代替完整备份。

用户可选择记住登录或清除本机教务登录；当前只提供手动读取。未发布源码补充导入和撤销的只读变化明细。周期检查、持久待确认更新和合并手动课程尚未开放；课表变化未来只在 App 内提示，系统通知仅保留导航行程，详见 [教务适配](decisions-academic-import.md)。

图片与任意未适配网页不直接作为通用课表输入；可自行整理成 JSON。应用只提供可复制的整理提示词，不自动将截图或课表发送给外部工具。草稿和返回规则见 [导航交互](navigation.md)，访问边界见 [权限说明](permissions.md)。
