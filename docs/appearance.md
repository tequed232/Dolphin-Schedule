# 外观与资源

应用使用 Kotlin＋Jetpack Compose 保留原有列表、平铺、卡片和配色。默认使用主题底色，不附带背景图片；只有用户选择并启用图片后才显示自定义背景。原生外观设置包括背景、模糊、深浅模式、动态取色、显示大小、安全区和性能模式。

## 使用外观设置

在“设置 → 外观”调整深浅模式、文字尺寸和背景。深浅模式可跟随系统；Android 的动态取色依赖受支持的系统环境。原生主题沿用项目的青色强调色、灰色表面和五组课程配色。

在“背景”页面选择 JPG、PNG 或 WebP。单张不超过 10 MB，图片在本机处理、缩小和保存，不上传；推荐使用 1080×1920 或 1440×2560 的竖图。居中铺满会按屏幕裁去部分边缘。

选图后可调节 0–30 px 模糊：拖动时预览，松手后保存。“使用主题底色”关闭图片显示并保留已选文件；“启用这张图片”重新显示；“移除图片”删除已保存的背景。未启用图片时，模糊控件禁用。

原生选图通过系统文件选择器获得内容 URI，不申请相册或外部存储读取权限；只读取用户所选文件，不额外保留长期访问授权。JPG / PNG / WebP 在本机校正方向、缩至最长边 1920，再压缩保存；原图最大 4000 万像素，处理后的编码不超过 300 万字符。损坏或过大图片保留原背景。选图期间只保存背景校验摘要，其他窗口已更换背景时阻止旧结果覆盖。

“屏幕安全区”支持上下自动留白或 0–100 dp 手动调整。主界面、课程编辑和教材编辑使用同一规则；横向屏幕切口与键盘始终自动避让。手动值和主题、字体设置随完整应用备份保存。

自动性能模式在低内存设备或交互掉帧时降低背景采样开销，课程文字不参与模糊。只在交互后采样 24 帧，按实际刷新率判断，空闲时不运行帧循环；完整效果模式保留较高背景细节。快速模糊拖动合并处理，解码和模糊结果使用有界内存缓存，不把缓存或测试图片打进 APK。

## 课表布局与时间轴

底部胶囊覆盖在滚动内容上，四周和系统手势区都可透出课表；只有滚动内容末尾保留避让距离，末节课程仍能滚到胶囊上方。列表不再显示每两节间的“课间”文字。列表和平铺共用时间轴，跨节课程保持连续高度。

学校名为“中午…”或“午休…”且没有任何课程占用的时段自动收起，不删除教务原始编号。若该时段确有课程，仍完整显示。点按左侧时间，或进入“设置 → 上课时间”，可修改节次名称与起止时间，也可确认删除不使用的节次；后续课程的索引同步前移，实际上课时间保持一致。有课程占用时阻止删除，需先调整相关课程。其他窗口已修改课表时，旧编辑窗口不能覆盖新数据。

当前时间线为半透明强调色横线，显示在今天或包含今天的当前周，按真实起止时间定位，每分钟更新；课间与收起的午休在相邻时段之间连续定位。时间不明确或早于首节、晚于末节时不绘制，不在浏览其他日期时显示错误的“现在”。

平铺中普通横滑浏览课表，到边缘后的下一次向外滑动翻周；长按课程进入位置调整，拖动卡片改变星期和开始节次，上下把手单独调整起止节次。拖到可视区域边缘会继续横向或纵向滚动，但不会在拖动期间跨周改写周次。收起的午休不是放置目标，整块移动保持原有连续节数。点空白、返回或“完成”退出选择；系统取消手势时丢弃预览。松手后才保存，遇到冲突先确认，保存前重新核对课程、作息和冲突；其他窗口的更新不能被旧手势覆盖。课程名称、教师、地点、周次、备注、配色和教材关联保留。辅助功能提供按天、按节移动与把手调整操作。

胶囊切换移除了叠加的尺寸动画；空课表格使用 Canvas 批量绘制，课程布局按课表与日期缓存。页面滚动状态随标签保存，350 ms 内重复的列表/平铺偏好保存会合并，数据没有变化时不重复提交 SQLite。真机帧耗时由独立验收测试记录，调试包结果用于前后对比，不代表所有设备的帧率保证。

## 资源与维护

| 资源 | 用途 |
|---|---|
| `app/src/main/res/drawable-nodpi/app_icon.webp` | 唯一品牌源图与应用图标 |
| `app/src/main/res/drawable-nodpi/live_icon.webp` | 系统通知的小尺寸品牌图 |
| `app/src/main/res/drawable/ic_notification.xml` | 系统着色的单色通知图标 |
| `app/src/main/kotlin/com/dolphin/schedule/ui/navigation/CapsuleNavigation.kt` | Compose 绘制的胶囊导航图形 |

旧 Web 资源清单、SVG 子集和生成品牌副本均已移除。替换资源时同步源码准入、第三方说明与必要验证，不引入网络字体作为离线使用的前提。生成资源放 `app/build/`，设备截图与测试图片放忽略的 `build/`，不随源码分发。

导航、课程、文本与图片应适配窄屏/宽屏、横屏/竖屏和深浅模式。应用不提供电脑模式或手动屏幕方向切换按钮。项目代码采用 [MIT](../LICENSE)，作者品牌图和第三方资源的来源见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

“设置 → 数据与备份”的完整备份包含背景、教材与偏好；普通课表 JSON 只导入课表内容，二者用途不同，见 [数据说明](data-and-migration.md)。
